🎨 応力アート (STRESS ART)

構造にかかる「応力」を4つのタイプに分けて色で可視化。2級試験ではどの色（応力）がどこに出るかを問われる。

📌 応力の4種類（短大生向け解説）

建築物には「応力＝力の集まり」が4種類ある。それぞれが「どんな色」か覚えよう。

  • 曲げ応力（σ）：はりが曲がると生じる。上側が圧縮、下側が引張。建築士試験最頻出。
  • せん断応力（τ）：はさみで切るような力。Mmaxの位置ではせん断力S=0、Smaxの位置ではM=0。
  • 引張応力：ケーブル・ボルトなど「引っ張る」部材に働く。鉄骨棒鋼の接合部で重要。
  • 座屈（圧縮による挫曲）：柱が細長いと「ガタン」と曲がって壊れる。長細比λ=120が目安。

🏗️ 1. 曲げ応力 σ

梁が曲がると生じる。上側が圧縮（赤）、下側が引張（青緑）。

σ = M / Z [MPa]

✂️ 2. せん断応力 τ

はさみで切るように働く。梁の内部で斜めに分布。

τ = S·Q / (I·b) [MPa]

🔗 3. 引張応力

ケーブルやボルトが引っ張られる。吊り橋のケーブルが代表。

σ = P / A [MPa]

📉 4. 座屈（長細比）

細長い柱が「ガタン」と曲がる。長細比λが大きいほど危険。

λ = Lk / i　i=√(I/A)

📝 2級試験 頻出ワンポイント

  • 「曲げとせん断の関係」 → 曲げモーメントが最大の位置ではせん断力はゼロ（S=0）。せん断力が最大の位置では曲げモーメントはゼロ（M=0）。
  • 「同じ断面でも高さが違うと？」 → Z=bh²/6 だから高さを2倍にすると4倍強くなる。幅を2倍にすると2倍しか強くならない。
  • 「座屈とは？」 → 細長い柱が圧縮で曲がって壊れること。鉄筋コンクリートの柱も配筋で細長くなりすぎるとダメ。
  • 「角形鋼管が強い理由」 → 同じ断面積でも断面二次モーメントIが大きいから。円形より直角で広がった形が曲げに強い。
