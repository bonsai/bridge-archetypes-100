🌉 吊り橋の力学 (SUSPENSION)

吊り橋世界最長＝明石海峡大橋（3911m）。ケーブル（鋼ロープ）が引張力で全荷重を支える。 2級試験では「ケーブルの張力」と「主塔の圧縮」を問われる。

📌 吊り橋の仕組み（短大生向け解説）

吊り橋は「ケーブル（鋼ワイヤー）の引張力」だけで支える橋。 ケーブルは滑車のような形（パラボラ）に垂れる。そのカーブが「フェニー・カーブ」と呼ばれる。

  • ケーブル張力 T = √(H² + V²) ：水平分力H＋垂直分力Vの合成
  • 主塔（CとD）はケーブルからの力を受けて圧縮 → 建物の柱と同じ
  • ケーブルが風で揺れる → タコマナローズ橋（1940年）の風による倒壊が教訓
  • ロープウェイ・スキー場のリフトも同じ原理。身近な「吊り橋」。

🌉 吊り橋

  • 力：引張（ケーブル）＋圧縮（主塔）
  • 材料：鋼（高張力鋼）
  • アンカー：岩盤に固定
  • スパン：〜4000m可能
  • たわみ：風に揺れやすい

📝 2級試験 頻出ワンポイント

  • 「吊り橋に働く力」 → ケーブルは引張、主塔は圧縮。
  • 「アーチ vs 吊り橋」 → アーチは圧縮、吊り橋ケーブルは引張。両者は対をなす構造と言える。
  • 「なぜ長大橋に向く？」 → 一つのケーブルが連続的に引張を分担するため、桁橋よりも自重が軽い。
  • 「タコマナローズ橋の教訓」 → 風による振動（うなり）を考慮しない設計は危険。
