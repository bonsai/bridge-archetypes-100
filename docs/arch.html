🌉 アーチ橋の力学 (ARCH)

アーチは「推力（水平力）」で荷重を支える。梁と違って圧縮力しか出ないのが特徴。 2級試験では「アーチ脚部の反力の向き」を問われることが多い。

📌 アーチの仕組み（短大生向け解説）

梁は荷重をかけると曲がる（曲げモーメント）。 アーチは荷重をかけると「圧縮力」で押し返す。 だからアーチは「圧縮に強い石材・コンクリート」に向いている。

  • アーチの内部には圧縮力しか発生しない → 石材は圧縮に強く引張に弱い → 相性がいい
  • 脚部には水平反力Hが生じる → これを「推力」と呼ぶ
  • 推力を受け止める基礎（アバットメント）が頑丈でないと、アーチは後退して壊れる

🌉 アーチ橋

  • 主な力：圧縮力のみ
  • 反力：斜め（水平＋垂直）
  • 材料：石・コンクリート・レンガ
  • たわみ：小さい
  • 弱点：基礎（アバットメント）が要頑丈
  • 代表例：ローマの水道橋、万松寺橋

🏗️ 桁橋（梁）

  • 主な力：曲げ＋せん断
  • 反力：垂直のみ（単純梁の場合）
  • 材料：木材・鋼・RC
  • たわみ：比較的大きい
  • 弱点：長スパンだとたわみが大きくなる
  • 代表例：木造住居の床梁

📝 2級試験 頻出ワンポイント

  • 「アーチ橋の脚部反力」 → 垂直だけでなく水平反力（推力）がある。
  • 「アーチに適した材料」 → 圧縮に強い石・コンクリート。引張に弱くても大丈夫。
  • 「アーチの弱点」 → 基礎（アバットメント）の移動・沈下。基礎が動くとアーチは壊れる。
  • 「アーチと吊り橋の違い」 → アーチは圧縮、吊り橋はケーブルが引張で支える。
