🔺 トラス橋の力学 (TRUSS)

トラスは「三角形の組み合わせ」。節点法で各部材の力を計算する。 2級試験では「ゼロ力材」を3秒で見つける力が必要。

📌 トラスの基本（短大生向け解説）

トラスとはまっすぐな棒（部材）を三角形に組んだ構造。 三角形は「形が崩れない」（安定）だから、建物や橋に使われる。

  • 部材には軸力（引張または圧縮）しか発生しない → 曲げモーメントがない
  • 節点（ピン接合）では力の釣り合い → ΣFx=0, ΣFy=0
  • 引張 = 部材が引っ張られる（色：青緑） | 圧縮 = 押される（色：赤）
  • 部材数xと節点数jの関係：2j = x + 3 で静的決定

🔥 ゼロ力材の鉄則（試験頻出）

ゼロ力材＝力がはたらいていない（不要な）部材。見つけると計算が劇的に楽になる。

ルール1: 節点に3本の部材が交わり、うち2本が同一直線 → その2本以外の部材はゼロ力材。

ルール2: 節点に2本だけ部材が交わり、外力がない → 両方ゼロ力材。

覚え方: 「3本で2本一直線 → 3本目は0」

📝 2級試験 頻出ワンポイント

  • 「トラス部材の力は？曲げ？せん断？」 → 「軸力（引張・圧縮）のみ」
  • 「この構造は不安定？」 → 三角形の個数を確認。三角形で区切られていれば安定。
  • 「どの部材が引張？圧縮？」 → はりの下側は引張、上側は圧縮。それをトラスに置き換えるイメージ。
  • 「トラス→長スパンで軽量にする構造」。部材が細くても三角形の力の流れで大丈夫。
